# scripts-and-utils
Scripts and Utilities

- [Razer battery and system widget](razer-battery/README.md): a small Windows display for Cobra HyperSpeed battery, CPU/GPU activity, and system temperature.
- [Right Middle](right-middle/README.md): a small native right-click / hold-for-middle mouse remapper.
- [Local Agent Room](agent-room/README.md): a Windows viewer, durable agent inboxes, tickets, and moderator controls for local sessions.

App icons are original artwork generated by `tools/GenerateAppIcons.ps1`, which rewrites each app's checked-in `.ico` files. Add `-Preview -PreviewPath <file.png>` to render a comparison sheet. Builds embed the existing files and do not run the generator.
